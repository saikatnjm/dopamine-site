# Phase 49: Pro-level SEO for every game and page

**Status:** step A built (PR branch `seo/technical`, waiting for the owner); steps B and C next · **Written:** 2026-10-26 · **Estimated size:** about 3–4 days in 3 PRs

**Index:** [ideas backlog](2026-10-25-ideas-backlog.md)

## 1. Goal

Make every indexable page as findable as it can honestly be, in **English and Bangla**:

- correct, unique, non-truncated titles and descriptions;
- rich structured data;
- a share preview image for every game;
- crawlable "how to play" text;
- real Bangla URLs that Google can index.

The audience searches in both languages ("latim game", "লাটিম খেলা", "বই ক্রিকেট").

**Baseline (2026-10-26 audit):** every indexable page already has a title, description, canonical and
sitemap entry. Game pages have `VideoGame` / `Quiz` JSON-LD; guides have breadcrumbs and an FAQ.

**Gaps:**

1. Bangla is a cookie on the same URL, so crawlers (no cookies) only ever see English.
2. 11 older games have no per-game OG image (they fall back to the site card).
3. Game pages are thin: H1, one line, the game.
4. No `BreadcrumbList` on games, experiences or categories; no `ItemList` on `/games`, `/experiences` or
   categories; no `Organization`; game JSON-LD lacks image and publisher.
5. Some titles and descriptions are truncated in results (up to 80 + " · Hottogol" chars).
6. No Search Console verification hook, and no automated checks for duplicate or too-long metadata.

## 3. Step A: technical SEO (PR 1)

| Item | Detail |

| Length rules | Full title (with " · Hottogol") ≤ 60 chars where possible, hard limit 70; description 110–160. `tests/seo.test.ts` checks every registry entry and static page, plus uniqueness of titles and descriptions across indexable pages |

## 4. Step B: Bangla URLs (PR 2)

- **Routing:**
  - `proxy.ts` (Next 16's middleware) rewrites `/bn/<path>` → `/<path>` and sets the request header
    `x-hottogol-lang: bn`.
  - `getLang()` reads the header first, then falls back to English.
  - Visiting an unprefixed URL with `lang=bn` in the cookie → 307 to `/bn/<path>`. Crawlers send no
    cookie and are never redirected.
  - Static files, `/_next`, `/api`, OG images, the sitemap and robots are excluded from the proxy.
- **Links:** `components/i18n/link.tsx` = `next/link` that adds `/bn` on Bangla pages, swapped into all
  files that import `next/link`. Programmatic navigations (`router.push`, `location`) use the same
  `localePath()` helper.
- **Language toggle:** navigates to the other language's URL and still writes the cookie as the
  preference.
- **Metadata:**
  - `pageMetadata` adds `alternates.languages` = `{ en, bn, "x-default": en }`, with a self-canonical
    per language.
  - Bangla pages get Bangla titles and descriptions: `seo.bn` in the registries; guides and static pages
    get BN SEO strings.
  - `openGraph.locale` = `bn_BD` / `en_US`.
- **Sitemap:** every indexable URL is listed with `alternates.languages` (Next supports it).
- **OG images** stay English (Satori can't shape Bangla). `og:title` and `og:description` are Bangla on
  `/bn` pages.
- **Share and challenge links** keep their current paths; the recipient's cookie or toggle decides the
  language. `/c` and `/result` are noindex either way.
- **AGENTS.md:** replace "Same URLs for both languages" with the new rule.

## 5. Step C: content (PR 3)

- **Per activity** (all games, simulators, quiz, tools), in `data/how-to/<slug>.ts` or a field on the
  registries:
  - **"How to play":** 3–5 steps.
  - **Tips:** 2–3.
  - **FAQ:** 3 questions with honest answers: what it is, controls, how scoring, challenges and
    sharing work, privacy (nothing is uploaded).
  - EN + BN.
- **Rendering:** server-rendered under the game in a `<details>`-free, readable section. It needs no
  client JS and must not push the game below the fold on phones.
- **JSON-LD:** `FAQPage` only where the FAQ is visible. Google now shows FAQ rich results only to some
  authoritative sites, so this is for relevance and AI answers, not stars.
- **Validation** (in `tests/seo.test.ts`): every playable activity has content, no paragraph repeats
  across pages (like `lib/guides.ts`), and nothing claims numbers we don't have.
- **Keywords:** used naturally in English and Bangla (e.g. "book cricket online", "বই ক্রিকেট খেলা",
  "লাটিম খেলা", "মার্বেল খেলা").
- **Never:** stuffing, fake reviews, invented statistics.
