# Dialect content (আঞ্চলিক ভাষা)

This folder powers three things:

- **শব্দের মানচিত্র** (`/games/word-map` plus one page per region)
- **তুমি কোন এলাকার মানুষ?** (`/games/which-region`)
- **আঞ্চলিক ভাষার লড়াই** (`/games/ancholik-quiz`)

Everything is TypeScript, with no database. Types live in `lib/dialects/types.ts`.

## The model: concepts × regions

- **Concept** (`concepts.ts`): one thing to compare, written as the standard word or phrase: বিড়াল, কোথায়, "কোথায় যাচ্ছ?".
- **Regional form** (`forms/<region>.ts`): what a region calls that concept, exactly as a source wrote it, with sources, confidence and a review status.
- **Dialect region** (`regions.ts`): a dialect area and the districts where it is *mainly* spoken. Regions are not districts: borders are fuzzy and one word can live in several regions.
- **District** (`districts.ts`): all 64 districts. The map (`map.ts`, generated by `scripts/build-map.mjs` from geoBoundaries, CC BY 3.0 IGO) has one shape per district.
- **Source** (`sources.ts`): every cited work (title, URL, type).

## Who sees what

| Form status | Map + detective (as "sourced") | Scored quiz |
| --- | --- | --- |
| `draft` | no | no |
| `needs_review`, confidence `high` or `medium`, Bangla script | **yes**, with its source and a "📚 not yet checked by locals" note | no |
| `needs_review`, confidence `low`, or romanized / rendered | no | no |
| `verified` (a person checked it) | yes, with "✅ checked by people" | **yes** |
| `rejected` | no | no |

**Code never verifies a dialect fact.** Only a person who knows the dialect sets `verified`. The
validator checks structure only.

## Rules

- **Never invent.** A form must come from a source you actually read. Copy the spelling exactly;
  put other spellings in `variants`. If you only have Latin letters or IPA, use `script: "romanized"`;
  it stays hidden until someone writes the Bangla and verifies it.
- **Area:** `regions` is the dialect region. Put anything narrower the source says in `area`
  (e.g. "Banaripara", "Chuadanga").
- **Confidence:**
  - `high` = a reputable source (encyclopedia, academic, dictionary) or 2+ independent sources agree
  - `medium` = one decent source (a government portal, a newspaper)
  - `low` = a blog or social post (never shown)
- **Ids:** never rename or reuse an id. Forms use `<region>-<concept>[-n]`. Concept ids appear in URLs (`?c=`).
- **Order:** `regions.ts` is **append-only**, because a region's position is packed into quiz challenge seeds.
- **Tone:** keep humour about words, never about people or districts. Leave out caste-linked
  expressions, slurs and anything tied to tragedies.

## Add things

- **A word:** add a `RegionalForm` to `forms/<region>.ts`, cite a source (add it to `sources.ts`
  first if new) and set `status: "needs_review"`.
- **A concept:** add it to `concepts.ts`. It appears on the map once it has public forms, and becomes a
  detective question once forms cover at least 4 regions.
- **A region:** append it to `regions.ts` with its districts (each district may be in only one region),
  add a fill colour and label position in `lib/dialects/map-layout.ts`, create `forms/<region>.ts` and
  add it to `index.ts`.

## Review and publish

```bash
docker compose run --rm dev npm run content:checklist   # writes review/YYYY-MM-DD-dialect-review-checklist.md
docker compose run --rm dev npm run validate:content    # structural report; fails on errors
docker compose run --rm dev npm test                    # unit tests
```

The checklist lists every form not yet verified, grouped by region, with sources and tick boxes.
For each one, edit the form:

- **Correct:** `status: "verified"` (fix the spelling first if needed). Verified forms also become
  scored quiz questions: "এই শব্দের মানে কী?", with three other standard words as wrong answers.
- **Wrong:** `status: "rejected"` and a `notes` line saying why.
- **Unsure:** leave it as `needs_review` and add a note.

## Where the current data came from

Web research done on 2026-10-25, with every source opened and cited. The full report is
`resources/2026-10-25-regional-dialect-research.md`. It was imported as 282 forms (high/medium only,
all `needs_review`); 239 of them are public. Weak areas: Cumilla (mostly romanized sources), Old Dhaka
and Bogura (few words), and the Chittagong Hill Tracts (not covered: indigenous languages).
